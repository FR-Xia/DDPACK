DDPACK 1.1.0 distribution
========================

The source distribution contains MATLAB and independent C++ implementations,
formal examples, tests, a Chinese manual, English entry-point documentation,
licenses, citation metadata and current measured evidence. Native use does not
require MATLAB. The supported extension contracts differ as documented in
``cpp/README.rst`` and the manual.

Run tests after building/installing from a clean source extraction. Verify the
source ZIP with SHA256SUMS.txt and the release payload against the supplied
manifest. Release assets and the fixed source tag are at
https://github.com/FR-Xia/DDPACK/releases/tag/v1.1.0.

GitHub Actions exercises C++ builds/installation and MATLAB tests/examples.
Only actual completed runs establish platform validation; consult the run
results at https://github.com/FR-Xia/DDPACK/actions.
